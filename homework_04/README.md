# Homework 4 — Power BI Dashboard for Yellow Taxi Trips

This final task continues the RDBMS ETL project based on `yellow_tripdata`.

The goal of this homework is to build an analytical Power BI dashboard using the prepared fact table and dimension tables.

## Dashboard requirements

The dashboard includes:

- daily revenue chart for a selected month;
- distance range filter;
- passenger count filter;
- airport trip filter;
- data model screenshot;
- filters screenshot;
- final dashboard screenshot.
